# Contributing

Submit focused pull requests with tests and source references for protocol or
setting mappings. Contributions are under the root MIT license unless clearly
identified as separately licensed third-party material. Preserve upstream notices.
Do not contribute credentials, recordings, APKs, decompiled proprietary code,
firmware, or unverified setting ranges. Document model and firmware limitations.

Run `python -m pytest tests/test_bridge.py tests/test_web.py tests/test_camera_settings.py`.
Run `node --check bridge/static/app.js` and `node --check bridge/static/settings.js`.
