    ONBOARDING / CONFIGURATION

    From Blink to your network.

    Pair the camera with Wi-Fi in the Blink mobile app once. Everything for this bridge—account verification, camera selection, streaming and ONVIF—can then be managed here.

    01

    Connect Blink

    Your password and verification code are never returned to the browser. Saved authentication stays on this computer. Stop camera streams before replacing the account. Refreshing an existing account does not interrupt video.

    02

    Select a camera

    Add a camera from your account or edit an existing connection. Stop its stream and ONVIF service before changing settings.

    Extended is a request, not a guarantee. Monitor shows the mode Blink actually grants. Continuous requests can drain battery-powered cameras quickly.

    03

    Local network

    Use this server’s LAN address. Protect must be able to reach it on the ONVIF port and TCP 8555.

    Native Windows mode uses 127.0.0.1:8787; container mode uses the server address and an admin password. Closing the browser leaves streams running.

    04

    Start & adopt

    Start a stream in Monitor and capture a frame to check it. Enable ONVIF and discovery, then adopt the camera in Protect.

    Keep the camera’s generated UUID and MAC identity unchanged after adoption. No camera firmware modifications are used.
